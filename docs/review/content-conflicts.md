# Content conflicts — live site vs redesign

**Internal. Not linked publicly, not in the sitemap, not indexed.**

Re-crawled `https://southdademusic.com` live (cache bypassed) during the
pre-client-review pass. Every row below is a contradiction **inside the client's
own current site**, not a disagreement between us and them. None is resolved by
invention — each needs an owner decision.

---

## 1 · Performance guarantee — unconditional vs conditional

| | |
|---|---|
| **Source A** | Homepage banner, live today: *"Every Student Steps on Stage Within 90 Days."* |
| **Source B** | Homepage FAQ, live today: *"every student performs in a live showcase within 90 days"* |
| **Source C** | `/90-day-stage-program/`: students *"get the chance to perform"* |
| **Conflict** | Two places state it unconditionally; the programme's own page states it conditionally. |
| **Redesign value** | The conditional only. The words "every student" appear nowhere. |
| **Owner decision** | **Required.** Is the unconditional promise true and defensible? If yes we can publish it and it is a strong claim. If not, the live homepage is currently over-promising. |

## 2 · Lesson frequency — one class or two

| | |

## Not carried over, deliberately

**The mission statement.** Live text: *"…for families searching for Music Lessons
Near Me and trusted Kids Music Classes South Dade."* That is keyword copy, not a
mission. The fact (simple, clear music education; skill, confidence, progress) is
preserved; the SEO phrasing is not.

**"Music Lessons Near Me" / "Kids Music Classes South Dade" as body copy.** These
appear mid-sentence throughout the live site. Facts kept, phrasing dropped.

**"Class mein performance"** — an untranslated word in the live Week 11 line.
Corrected to *"Peer exposure — they play for the class."*

**"Exceution"** — a live typo in the four-pillar block. Not reproduced.
